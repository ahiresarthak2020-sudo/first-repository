# ASS No. 9 — React Counter App Using useState

## Aim
To develop a React Counter App using the useState Hook.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Add +1: Increases the counter by one.
- Minus -1: Decreases the counter by one.
- Reset: Sets the counter back to zero.
- Dynamic counter display using React state.

## Concept Used
The useState Hook stores and updates the counter value. Whenever the state changes, React updates the displayed value automatically.

## How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.

## Result
The React Counter App was created successfully with Add, Minus, and Reset buttons.
