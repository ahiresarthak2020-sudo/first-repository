# ASS No. 10 — React Text Input and H1 Display

## Aim
To create a React application that accepts text input from the user and displays it in H1 heading format.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Concepts Used
- React useState Hook
- Controlled input
- Event handling using onChange
- JSX and H1 heading element

## Features
- Accepts text from the user.
- Displays the entered text immediately as a large heading.
- Updates the output whenever the user changes the input.
- Shows a placeholder message when the input is empty.

## How to Run
1. Install Node.js.
2. Open the project folder in Terminal.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL displayed in Terminal.

## Result
The React application successfully accepts user text and displays it in H1 format.
