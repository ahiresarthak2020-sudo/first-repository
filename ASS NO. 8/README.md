# ASS No. 8: MongoDB Student CRUD API

## Aim
To develop a Student CRUD API using Express.js and MongoDB.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript

## Description
This project implements a REST API to create, retrieve, update, and delete student records stored in MongoDB.

## Student Details
- Name
- Age
- Course
- Email

## API Endpoints

| HTTP Method | Endpoint | Operation |
|---|---|---|
| POST | /students | Create a student |
| GET | /students | Retrieve all students |
| GET | /students/:id | Retrieve a student by ID |
| PUT | /students/:id | Update a student |
| DELETE | /students/:id | Delete a student |

## How to Run
1. Install Node.js and MongoDB.
2. Run npm install.
3. Start the server using node server.js.
4. Test the endpoints using curl or Postman.

## Database
Database name: studentDB

## Result
The Student CRUD API was implemented and tested successfully. All CRUD operations worked correctly.
