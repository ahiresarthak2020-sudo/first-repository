# JavaScript API Operations

A beginner-friendly practical demonstrating REST API operations using JavaScript.

## Operations Demonstrated
- GET: Retrieve users
- POST: Create a user
- PUT: Update user data
- PATCH: Partially update user data
- DELETE: Delete a user

## Technologies Used
- JavaScript
- Node.js
- Fetch API
- JSONPlaceholder REST API

## How to Run

1. Install Node.js.
2. Open the terminal in this folder.
3. Run:

   node api.js

## API Endpoint

https://jsonplaceholder.typicode.com/users

Note: JSONPlaceholder is a testing API. Changes are simulated and are not permanently saved.
