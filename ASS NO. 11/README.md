# ASS No. 11 — Daily Mood Card

## Aim
To develop a React mini app using the useState Hook that lets users enter their name, select their mood, and view a live mood card.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Features
- Accepts the user's name.
- Allows the user to select a mood.
- Displays a live greeting, emoji, and mood message.
- Updates the card automatically when inputs change.
- Reset button clears the name and restores the default mood.

## Concepts Used
- React useState Hook
- Controlled components
- onChange event handling
- JSX and conditional rendering

## How to Run
1. Install Node.js.
2. Open the project folder in Terminal.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL displayed in Terminal.

## Result
The Daily Mood Card app was created successfully using React useState.
